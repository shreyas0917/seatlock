SEATLOCK API · GO (CHI)

POST /v1/holds

Redis lock first (fail closed: 503 if Redis is down), then the hold transaction in Postgres. Hold = 5 minutes.

POST /v1/bookings

Idempotency-Key claimed in Postgres (lease), then
Tx A → gateway → Tx B.
Lost answer → 504, payment stays PENDING. Never touches Redis.

GET seat map · DELETE hold

Seat status from Postgres only.
